## 📄 Documentación y Muestra Visual

Dado que la integración con la API de Google Calendar estaba asociada a credenciales de un entorno institucional cerrado, se incluye la documentación completa en formato PDF con la guía visual paso a paso de toda la aplicación:

* 👤 **[Manual de Usuario — Paciente](./docs/Manual_usuario_Paciente.pdf):** Recorrido completo de la interfaz pública. Muestra el flujo de ingreso al sistema, formulario de registro con validaciones, navegación por el calendario interactivo, reserva de tramos horarios y la pasarela de pagos.
* ⚙️ **[Manual de Usuario — Administrador](./docs/Manual_usuario_Administrador.pdf):** Guía orientada a la gestión interna de la clínica podológica. Explica la administración de citas, control de pacientes, configuración de horarios disponibles y gestión de servicios.
